# 奶蛙动画素材来源

`app_icon.png` 和 `app_icon.ico` 是本项目新增的工科学者奶蛙应用图标，基于上游奶蛙形象制作；它们不是上游仓库原图。由于图标沿用了上游角色形象，仍应遵循上游及原始来源适用的授权要求。

本目录的六组透明 PNG 动画帧（待机、大笑、挥手、睡觉、打拳、八卦）和 `icon.ico` 取自 [BUWANNAB/naiwa](https://github.com/BUWANNAB/naiwa)，固定版本为 [`d1457ddb608de7f00699f118b730f7cd84f4671c`](https://github.com/BUWANNAB/naiwa/tree/d1457ddb608de7f00699f118b730f7cd84f4671c)。本项目未修改这些图片的角色像素。

上游 [ASSETS_NOTICE](https://github.com/BUWANNAB/naiwa/blob/d1457ddb608de7f00699f118b730f7cd84f4671c/ASSETS_NOTICE.md) 将待机、大笑、挥手、睡觉图片来源标注为 [woainiunai/yellow-belly-creature-desktop](https://github.com/woainiunai/yellow-belly-creature-desktop/tree/45857f860a221a4af1fd2469d658cc7ad8b4462e)，并将打拳、八卦动作来源标注为 [lyhkevin/Codex_pet_naiwa](https://github.com/lyhkevin/Codex_pet_naiwa/tree/aa6dc78ab2c623d28274b232101cc1270e928204/gifs/extras)。

角色图像和动画的权利归各自权利人。本说明记录来源，不授予或改变素材的授权状态；请在分发前遵循上游及原始来源适用的授权要求。素材署名或移除请求可通过本项目 Issue 提交。
