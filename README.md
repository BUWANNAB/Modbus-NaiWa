# 奶蛙 Modbus 工作台

Windows 桌面 Modbus 调试工具，把 Modbus Poll 常用的主站监视操作和 Modbus Slave 的 TCP 从站模拟放进一个奶蛙主题工作台。主窗口采用 MDI 数据窗，连接参数可停靠，暖灰、奶油白和奶黄色界面不使用绿色主题。收到有效数据后可播放奶蛙风格笑声。

## 功能

- Modbus TCP 与 Modbus RTU（RS-485/串口）主站读取
- 功能码 01、02、03、04；连接后自动轮询、单次读取、手动停止，超时和失败重试可配置
- 主站数据窗采用 Poll 式简洁表格：左侧为 0 起始行号，可编辑 Name，列标题显示读取起始地址；连接后每轮自动覆盖更新，首个响应前显示“—”
- TCP 目标 IP、端口和本机绑定 IP 分开设置；默认目标 `192.168.100.15:502`、本机 `192.168.100.100`，连接状态显示实际本机地址到目标从站的路径；本机 IP 必须已配置在 Windows 网卡上，留空时交给系统路由选择
- 按 Modbus 限制校验单次读取量：线圈/离散输入最多 2000 项，寄存器最多 125 项；校验地址和数量不会越过 0–65535 地址空间
- UInt16、Int16、Hex、Binary、UInt32、Int32、Float32、UInt64、Int64、Float64 显示；支持 ABCD、CDAB、BADC、DCBA 四种字节/字顺序
- 读写状态行显示 TX/RX/ERR 计数、Unit ID、功能码和轮询间隔；往返延迟使用高分辨率计时并显示最近 100 次均值
- 手动写 FC05/06 及批量写 FC15/16；写入默认关闭，每次写入前再次确认，响应地址/数值/数量会与请求核对；双击读数可快速填入写入栏
- 工作区配置可保存/打开为 JSON 文件
- 轮询读数可按地址实时追加到 CSV，记录时间、设备、功能码、原始值与解析值
- Modbus TCP 从站模拟，可编辑线圈、离散输入、保持寄存器和输入寄存器完整 0–65535 地址空间；编辑器按 16 项分页定位，可在运行时更新模拟值
- 抖音奶蛙待机、大笑、挥手、睡觉、打拳、八卦六种动画；连接、读数和写入成功会触发相应动作，右键可预览；窗口与 EXE 使用工科学者奶蛙图标
- 主窗口按屏幕可用区域自适应初始尺寸并居中；缩放窗口时，当前主站/从站数据窗同步铺满可用区域
- 收到有效数据时播放奶蛙笑声提示音，可关闭或载入本地 WAV

角色图片素材的上游来源与权利说明见 [assets/mascot/ASSETS_NOTICE.md](assets/mascot/ASSETS_NOTICE.md)。

默认使用协议 **0 起始地址**；也可切换为 **1 起始设备地址**显示和输入，通信报文始终使用标准 0 起始地址。传统 4xxxx/3xxxx 编号请去掉区域前缀，再按设备手册确认地址基准；例如保持寄存器 40001 通常对应 0 起始协议地址 0。

## 直接运行源码

需要 Windows、Python 3.11 和网络连接以安装依赖：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run_app.py
```

## 使用提示

- 轮询间隔默认 1000 ms；RS-485 总线建议从较慢的间隔开始。
- 鼠标滚轮只负责滚动侧栏/窗口内容，不会意外改动数值框或下拉框；点击数值框的箭头或直接输入来调整参数。
- 连接 `192.168.100.15:502` 时，主站本机地址可绑定 `192.168.100.100`；Windows 网卡需已配置该地址且与目标设备网络可达。连接按钮会在连通后自动轮询，主站数据窗按设定间隔刷新表格。
- 通信记录默认收起，可通过“显示 → 通信记录”打开；表格 Name 列可双击编辑，保存工作区时会一并保存信号名称。
- 写操作默认关闭。请先核对设备、从站地址、寄存器地址和数据范围，再启用写入。
- 从站模拟默认仅监听 `127.0.0.1:1502`，仅本机可连接。要让局域网内的 PLC 连接，可将监听地址改为 `0.0.0.0`，并按现场网络策略开放对应端口。
- 该工具用于 Modbus 通信调试；软件断开连接不能代替设备的物理急停或硬件保护。
- 内置提示音为本项目生成的短促原创合成音效。若要使用指定的抖音原声，可在设置中载入本地 WAV 文件；仓库不附带未授权的网络音频素材。

## 当前支持边界

- 主站支持 Modbus TCP 和 Modbus RTU；从站目前提供 TCP 模拟，主站/从站各使用一个活动连接配置。
- 目前覆盖 PLC 调试最常用的读功能码 01–04 和写功能码 05、06、15、16。Modbus ASCII、UDP、TCP Security、RTU-over-TCP、多个独立并发主站数据窗、地址/站号扫描、实时趋势图、原始报文测试台及扩展功能码尚未集成。
- PyModbus 负责 TCP/RTU 帧封装和响应解析；本软件会校验返回项数及写入回显。实际设备支持的地址、轮询速率和响应时间仍由设备、串口适配器、网络和总线负载决定。
